Sincroniza cliente

Cria ou atualiza o cadastro de um cliente pessoa jurídica no ERP. Quando requestedAnalysis for igual a true, também será solicitada uma análise de crédito para o cliente.

Authorizations:
basicAuth
Request Body schema: application/json
required

Dados cadastrais e comerciais do cliente pessoa jurídica.

customerId
required
string <uuid>

Identificador único do cliente na VTEX.

corporateName
required
string

Razão social do cliente.

tradeName
required
string

Nome fantasia do cliente.

email
required
string

Endereço de e-mail corporativo do cliente.

document
required
string

CNPJ do cliente, com ou sem formatação.

stateRegistration
required
string

Inscrição estadual do cliente

homePhone
required
string

Número de telefone principal do cliente, incluindo o DDD.

requestedAnalysis
required
boolean

Indica se deve ser solicitada uma análise de crédito após a sincronização cadastral.

required
object (CustomerAddress)

Informações de endereço do cliente

Responses

Pedido

Operações para consulta de juros

Consulta juros

Consulta juros da condição de pagamento escolhida pelo cliente e retorna os items com o acréscimo rateado

Authorizations:
basicAuth
Request Body schema: application/json
required

requestBody retirado da documentação oficial da VTEX - Tax Services

orderFormId
string

Identificador único do formulário do pedido

salesChannel
string

Identificador único do canal de vendas

Array of objects (InterestrateRequest-items)

Lista de objetos que representam os produtos do pedido, onde dockId é um campo que se refere à identificação no sistema de logística que contém informações sobre o endereço

Array of items

Valor total do orderForm, detalhado em impostos, frete, descontos e preços dos itens

clientEmail
string

Endereço de email do cliente

Array of items

Lista de informações de envio

object (InterestrateRequest-clientData)

Informações sobre o cliente que fez o pedido

object

Lista de pagamentos, com informações referentes ao pagamento do pedido

object (InterestrateRequest-taxApp)

Objeto com campos personalizados específicos para a aplicação fiscal

Responses

Produção

https://wkrtswcddl.execute-api.us-east-2.amazonaws.com/vtex/rest/vtex/order/interest-rate
